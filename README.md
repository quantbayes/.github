# QuantBayes

QuantBayes builds evidence verification infrastructure for AI, scientific, clinical, engineering, and regulated workflows.

QuantBayes Studio helps users define evidence requirements, inspect available evidence, quantify evidence sufficiency, and preserve an auditable result trail.

The live platform is available at:

https://quantbayes.com

## Public repositories

The public repositories contain documentation, schemas, profile definitions, and reproducible public material for QuantBayes Studio.

Production application code, deployment configuration, authentication logic, billing logic, and protected infrastructure remain private.

## Core idea

A result should not be trusted by output alone. It should remain linked to the evidence profile, evidence matrix, QuantBayes run, result, and report used to produce it.

## Main project

`quantbayes_platform_public` is the public source for community-facing QuantBayes documentation, evidence profile schemas, and reviewed public profiles.
